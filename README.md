🛍️E-Commerce Frontend Website

A modern, responsive e-commerce frontend built with React, Vite, and Tailwind CSS.
This project includes product listings, category sections, responsive UI components, and a clean minimal design.

🚀 Features
⚡ Built using Vite for fast development & optimized production builds
🎨 Styled with Tailwind CSS
📱 Fully responsive design
🛒 Product listing cards
🔍 Modern UI layout
🧩 Component-based structure (React)
